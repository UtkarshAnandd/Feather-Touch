2. CURRENT ARCHITECTURE
--------------------------------------------------------------------------------

Build System:
- Eleventy (11ty) version 3.1.0 (@11ty/eleventy)
- Module System: ECMAScript Modules (`"type": "module"` in package.json)
- Runtime Requirement: Node.js >= 22 (enforced by `.nvmrc` and `engines.node`)
- Configuration File: `eleventy.config.js`
  - Input directory: `src`
  - Output directory: `_site`
  - Includes directory: `_includes`
  - Data directory: `_data`
  - Template formats: `njk`, `md`, `html`
  - Template engines: HTML template engine `njk`, Markdown template engine `njk`
  - Passthrough copies:
    - `src/assets/css` -> `_site/assets/css`
    - `src/assets/fonts` -> `_site/assets/fonts`
    - `src/assets/js` -> `_site/assets/js`
    - `src/assets/icons` -> `_site/assets/icons`
  - Path Prefix: Configurable via `process.env.PATH_PREFIX || "/"`

Templating & Rendering:
- Nunjucks (`.njk`) engine handles templating.
- Layout inheritance: `src/index.njk` uses `layout: layouts/base.njk`.
- Partials inclusion:
  - `{% include "partials/icons.njk" %}` in base layout.
  - `{% include "partials/header.njk" %}` in base layout.
  - `{% include "partials/footer.njk" %}` in base layout.
- Layouts available:
  - `src/_includes/layouts/base.njk`: Contains `<!DOCTYPE html>`, `<head>`, skip-link, preview-banner, `<main id="main-content">`, header, footer, script tags.
  - `src/_includes/layouts/page.njk`: Extends `base.njk`, adds an inner container and `{% block pageHeader %}`. (Note: Currently `page.njk` nests a second `<main id="main-content">` inside the outer `<main>` of `base.njk` if used).

CSS Architecture:
- Implemented in a single stylesheet: `src/assets/css/main.css` (1,588 lines, 37.9 KB).
- Structured into explicit CSS Cascade Layers:
  `@layer reset, tokens, base, layout, components, utilities;`
  - `@layer reset`: Modern reset (box-sizing border-box, smooth scrolling, image fluid widths, zero margin/padding).
  - `@layer tokens`: Self-hosted `@font-face` definitions, CSS custom properties for palette, typography scale, spacing scale, border radii, shadows, layout constraints, transitions, and focus rings.
  - `@layer base`: Semantic element defaults, heading scale with CSS `clamp()`, skip-link, keyboard focus styling (`:focus-visible`).
  - `@layer layout`: `.container` (max-width 1200px, 20px padding), responsive `.grid` utility classes, `.section` padding.
  - `@layer components`: Buttons (`.btn`, `.btn--primary`, `.btn--secondary`), cards, badges, trust-pills, banners, forms, FAQ details/summary styling, gallery placeholders, footer components.
  - `@layer utilities`: Text alignments, color utilities, display helpers, icon sizing.
  - `@media (prefers-reduced-motion: reduce)`: Overrides transitions and animations to 0.01ms for accessible motion reduction.

JavaScript Architecture:
- Native ES module: `src/assets/js/main.js` (62 lines, 2.2 KB).
- Loaded as `<script type="module" src="/assets/js/main.js"></script>` at bottom of `base.njk`.
- Lightweight responsibilities:
  1. Mobile navigation menu toggle (`#nav-toggle` toggles `#primary-nav.nav--open` and updates `aria-expanded`).
  2. Mobile navigation auto-close on link click.
  3. Admission enquiry form preview interaction (intercepts submit, checks honeypot field `extra_notes`, displays `#form-feedback` confirmation message, resets form).
- No third-party runtime JavaScript dependencies (zero external frameworks).

Build Process & Commands:
- Development Server:
  `npm run dev` -> runs `eleventy --serve`
- Preview Build:
  `npm run build` -> runs `SITE_MODE=preview eleventy`
- Production Build:
  `npm run build:production` -> runs:
  `node scripts/check-launch-gate.mjs && SITE_MODE=production eleventy && node scripts/check-budgets.mjs`
- Test Suite:
  `npm run test` -> configured as `playwright test` (Playwright and Axe installed in devDependencies; tests not yet authored).

Quality Gates & Automated Budget Checks:
1. `scripts/check-launch-gate.mjs`:
   Validates 12 mandatory fields in `src/_data/site.json` before allowing a production build. If any field is missing or false, the build terminates with exit code 1.
2. `scripts/check-budgets.mjs`:
   Enforces strict size budgets on compiled `_site/` output:
   - HTML per page <= 75 KB (Compiled `index.html` is ~63 KB)
   - CSS main <= 50 KB (`main.css` is ~37.9 KB)
   - Total JavaScript <= 40 KB (`main.js` is ~2.2 KB)
   - Total Fonts <= 120 KB (4 WOFF2 fonts total ~68 KB)

Deployment Assumptions:
- Output directory is `_site/`.
- Fully static, serverless-ready HTML/CSS/JS output.
- Can deploy directly to Netlify, Vercel, Cloudflare Pages, or GitHub Pages.
- Environment variables recognized:
  - `SITE_MODE`: "production" vs "preview" (defaults to "preview").
  - `PATH_PREFIX`: sets subpath root (defaults to "/").
  - `SITE_DATA_FILE`: custom path to site json (used in CI/testing).

Accessibility (a11y) Implementation:
- Semantic Landmarks: Full HTML5 semantic landmark structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<aside>`, `<footer>`).

- Motion: `@media (prefers-reduced-motion: reduce)` resets all transitions and animations to 0.01ms.

Performance Implementation:
- Third-Party Requests: ZERO. No external CDN fonts, external scripts, or tracking pixels.
- Typography: Self-hosted WOFF2 files (Bricolage Grotesque and Atkinson Hyperlegible Next). Preloaded/swapped locally (~68 KB total).
- JavaScript Payload: 2.2 KB total (zero dependencies).
- CSS Payload: 37.9 KB total (unminified, zero external frameworks).
- HTML Payload: ~63 KB compiled single page.
- Image Formats: Currently zero bitmap images loaded, avoiding layout shift (CLS).
- Budget enforcement: Automated script `check-budgets.mjs` verifies compliance on build.

9. EXISTING DESIGN CONSTRAINTS (FOR FUTURE REDESIGN)
--------------------------------------------------------------------------------

Any future visual or UX redesign must respect the following architectural and technical constraints to prevent breakage:

1. Data-Driven Section Rendering:
   Sections for Programmes (`programmes.json`), Day Routine (`daySequence.json`), Activities (`activities.json`), Recognition (`recognition.json`), FAQ (`faq.json`), and Gallery (`images.json`) are rendered using Nunjucks loops. Redesigns must maintain compatible data schemas or update the templates accordingly.

2. Performance Budget Limits (`scripts/check-budgets.mjs`):
   - HTML <= 75 KB per page
   - CSS main <= 50 KB
   - Total JS <= 40 KB
   - Total Fonts <= 120 KB
   Introducing heavy CSS libraries (e.g., Tailwind output > 50KB) or bloated JS frameworks will break CI production builds.

3. Zero External CDN Dependency:
   The project is designed to be completely self-contained. Fonts must remain self-hosted WOFF2; icons must remain local SVGs.

4. Form Honeypot & Feedback Structure:
   The admission form in `src/index.njk` relies on input `name="extra_notes"` and feedback element `#form-feedback`. Redesigning form markup must retain these hooks.

5. Single-Page Anchor System vs Multi-Page Ambition:
   Currently, all navigation is hash-based (`#about`, `#programmes`). While `navigation.json` defines potential subpages (`/about/`, `/programmes/`), only `src/index.njk` currently exists. Redesigns should maintain anchor stability unless full subpages are explicitly built.

6. Launch Gate Conditional Rendering:
   Templates use `{% if build.mode != "production" %}` and `{% if site.contact.phoneDisplay %}` to safely fall back to draft notices. These conditionals must not be removed until verified data is injected.
